# Yasmina bundle — лендинг подписки с Yasmina Lite в подарок

34 файла из переданного архива: 18 изображений, 4 видео, 12 голосовых фраз на английском и арабском. Исходные файлы сохранены без изменений.

- `images/` — изображения и обложки видео.
- `video/` — видео.
- `audio/voice/en/` — английская озвучка.
- `audio/voice/ar/` — арабская озвучка.
- `manifest.json` — список файлов и их размеров.
