# Ресурсы для LPC

Общий репозиторий публичных ресурсов лендингов. Для каждого сайта — отдельная папка с его названием.

```text
lpc-assets/
└── yasmina-bundle/
    ├── images/
    ├── video/
    └── audio/
```

Изменённым материалам даём новые имена. В коде страниц используем прямые ссылки, закреплённые за коммитом.
